# VueConfort 1.0.0

Première version publique de VueConfort.

- Grossissement Android et commandes flottantes après activation volontaire du service d’accessibilité.
- Profils de confort personnalisables et automatisations locales.
- Lecteur adapté utilisant le texte accessible à la demande, sans capture d’écran.
- Calibration et outils de dépistage visuel STANDARDIZED_V2 avec historique local.
- Configuration guidée, aide intégrée et options de confidentialité/réinitialisation.

VueConfort ne remplace pas des lunettes, un opticien, un ophtalmologue ou un diagnostic médical. Les données restent sur l’appareil.
