# Captures réelles — Galaxy S25

Capturées le 4 août 2026 par `adb exec-out screencap -p` sur le Galaxy S25 SM-S931B physique, Android 16, définition native 1080 × 2340. Les PNG n’ont subi ni génération, ni maquettage, ni retouche de contenu.

## Fichiers

- `01_accueil.png` — accueil ;
- `02_barre_flottante_chrome.png` — panneau flottant réel au-dessus de `vueconfort.fr` dans Chrome ;
- `03_grossissement.png` — loupe système réelle à 2×, confirmée par `dumpsys accessibility` ;
- `04_profils.png` — profils ;
- `05_reglages_visuels.png` — réglages visuels ;
- `06_lecteur_adapte.png` — lecteur avec son texte d’exemple intégré ;
- `07_tests_visuels.png` — menu des tests ;
- `08_regles_automatiques.png` — règles automatiques ;
- `09_comparaison.png` — comparaison avant/après ;
- `10_accessibility_disclosure.png` — divulgation préalable Accessibility API.

## Contrôle

Les huit premiers fichiers constituent la sélection recommandée. Les captures ont été contrôlées visuellement : pas de message d’erreur Compose, pas de donnée personnelle affichée et pas de texte tronqué après correction des deux anomalies détectées. Les barres système Android sont conservées pour attester de la capture sur appareil réel.
